## Governing equations and retained numerical cases

The base-MATLAB model represents an RMS Thevenin source and a passive load:

- `Z_s = R_s + jX_s`, `Z_L = R_L + jX_L`.
- `I = V_s/(Z_s + Z_L)` A RMS.
- `P_L = |I|^2 R_L` W and `Q_L = |I|^2 X_L` var.
- `P_av = V_s^2/(4R_s)` W.
- `tau = P_L/P_av = 4 R_s R_L/|Z_s + Z_L|^2`.
- `Gamma_m = (Z_L - conj(Z_s))/(Z_L + Z_s)` and `tau = 1 - |Gamma_m|^2`.
- Transfer level is `10 log10(tau)` dB; positive mismatch loss is its negative.
- Maximum available-power transfer requires `Z_L = conj(Z_s)`.

For the baseline, retained expected values are `I = 10 mA RMS`, load voltage
`0.5 - j0.5 V RMS`, `P_L = P_av = 5 mW`, `P_L = 6.989700043360188 dBm`,
`Gamma_m = 0`, and zero mismatch loss. The source resistance also dissipates `5 mW`, so unity
available-power transfer is not described as lossless efficiency.

The copied-reactance failure uses `Z_L = 50 + j50 ohms`: current becomes
`0.005 - j0.005 A`, `P_L = 2.5 mW`, `tau = 0.5`,
`Gamma_m = 0.5 + j0.5`, net reactance is `+100 ohms`, and mismatch loss is
`3.010299956639812 dB`. Python's built-in complex arithmetic and `math.log10` independently
reproduced these constants; MATLAB did not execute them here.

The model accepts only scalar values inside a broad overflow-safe calculation envelope:
`1e-12` through `1e6 V RMS`, source resistance `1e-9` through `1e12 ohms`, load resistance
`0` through `1e12 ohms`, and reactances from `-1e12` through `+1e12 ohms`. Accepted boundary
cases retain finite linear quantities. The retained maximum-stress case reaches more than
`4e14 A RMS`, `4e26 V RMS`, and `2e41 var` without a nonfinite linear result. Intentional
logarithmic limits remain infinite for zero transfer or a perfect mismatch-coordinate origin.
