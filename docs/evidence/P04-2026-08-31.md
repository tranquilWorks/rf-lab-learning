## Governing equations and retained numerical cases

The base-MATLAB model represents a matched, lossless, nondispersive one-way line. Both ports are
assumed terminated in a real characteristic impedance `Z_0`; impedance mismatch is not an input to
this bounded model.

- `c_0 = 299792458 m/s` and `v_p = velocity_factor*c_0`.
- `lambda_g = v_p/f` and `tau = l/v_p`.
- Positive electrical length is `theta = beta*l = 2*pi*f*tau = 2*pi*l/lambda_g`.
- With the declared `exp(+j*omega*t)` convention, `H = exp(-j*theta)` and unwrapped through phase is `-theta`.
- Wrapped through phase uses the half-open interval `[-180,180)`.
- The principal phase-equivalent length is the shortest nonnegative length within one guided wavelength; it is not an absolute-length estimate.
- The unwrapped phase slope is `d(phi_deg)/df = -360*tau`.
- A reflected wave would accumulate `-2*theta` on a round trip; that P01 reference-plane behavior is distinct from one-way P04 transfer.

At the baseline, `f = 1 GHz`, velocity factor is `0.66`, phase velocity is
`197863022.28 m/s`, guided wavelength is `0.19786302228 m`, and physical length is
`0.04946575557 m`. Retained expected results are `tau = 250 ps`, electrical length `90 degrees`,
`H = -j`, and wrapped/unwrapped through phase `-90 degrees`.

The broken path is `5*lambda_g/4 = 0.24732877785 m`: delay is `1.25 ns`, unwrapped phase is
`-450 degrees`, and wrapped phase remains `-90 degrees`. Its single-frequency phasor is identical
to the baseline quarter-wave path. The principal equivalent is therefore only
`0.04946575557 m`, missing exactly one guided wavelength (`0.19786302228 m`). Python's standard
`math` and `complex` operations independently reproduced these constants; MATLAB did not execute
them here.

The model accepts only scalar values in a bounded calculation envelope: `1 kHz` through `100 GHz`,
physical length `0` through `1000 m`, and velocity factor `0.1` through `1`. At the upper endpoints,
the model exercises more than three million finite phase cycles. The source snaps only
roundoff-sized residues at exact cycle boundaries before wrapping; values immediately on both sides
of the `-180/+180 degree` cut are separately retained.
