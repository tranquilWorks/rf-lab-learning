# Start here

This is the RF and Microwave Measurement interactive MATLAB track. Run `./bin/learn status`, then
`./bin/learn start`. P01 is the reference slice; each following module maps one-to-one to a Portfolio
Control batch. The manifest is the current implementation frontier: implemented modules open in
tutor mode, while scaffolded modules refuse to masquerade as finished lessons. A learner session
follows read → visualize → move one lever → visualize the change → read/explain, then a broken case,
checks, and teach-back.

P01, P02, and P03 are implemented learning slices. P03 connects P01's impedance/reflection view to
P02's power-ratio decibels through conjugate source/load matching.

Use `docs/CURRICULUM_AUDIT.md` for the complete phase and batch map.
